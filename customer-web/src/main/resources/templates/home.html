Decode either token by hand — no library, no jwt.io: a JWT is three base64url segments joined by dots: header.payload.signature. Take the middle segment, then in a terminal: 
echo '<payload segment>' | base64 -d
(add == padding if it complains about invalid length). You'll get the raw JSON claims — same content the table above already parsed for you, but now you've seen the mechanism, not the abstraction.
